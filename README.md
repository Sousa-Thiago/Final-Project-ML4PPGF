# Projeto Final de Machine Learning - PPGF UERJ

Repositório criado para o projeto final da disciplina de Machine Learning partes I e II - PPGF-UERJ

## Sobre o Repositório

`CNNvsMLP.ipynb`: Código principal da análise.
  - 1. Download dos dados do CMS Open Data.
  - 2. Preparação e pré-processamento.
  - 3. Construção e treinamento de dois modelos de deep learning (MLP e CNN 1D).
  - 4. Comparação objetiva via curva ROC e AUC.

## Aviso importante

- Esse código buscar amostras do Open Data CMS (link: `https://opendata.cern.ch/record/12102`) e faz o download de 1 arquivo de teste e 2 de treino.  
- O próprio código cria dois diretórios chamados de `test` e `train` apara armazenar as respectivas amostras de teste e treno.  
- Caso não queira fazer o download local das amostras é possível fazer uma cópia direta do meu CERNBox. Essa opção é mais rápida do que o download.  
- Vale ressaltar que o download não demora (aproximadamente 10 minutos).
